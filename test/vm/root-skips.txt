# root-suites job (sudo on a hosted runner) and `make vm-root-test` (a KVM guest). Any other skip fails the run:
# a skip exits 0 like a pass, so a test that stopped running as root went unnoticed there (review round 5, P1).
# Built from a guest run's skips (summary.json) and from the root-suites job's log on the runner, which has skips a
# guest does not. Add an entry only with the reason the test cannot run as root.
#

# BPF objects, which root-suites.sh runs beside its -tags tegobpf build: those tests need the objects, and the
# tagged build runs them. Every other entry is allowed in every suite.
#
# <package> <test> # <why it skips as root>
