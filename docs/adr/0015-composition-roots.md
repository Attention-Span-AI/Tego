# ADR 0015: an optional component is constructed where everything it needs can be named, and its absence is a gap

Status: accepted 2026-09-22. Refines ADR 0013 (lifecycle), which says who stops a goroutine; this says who starts it and from where.

Decision: a component that produces events for a run reaches `internal/runtime` in one of exactly three shapes, chosen by two facts about it — whether its package imports `internal/runtime`, and when the thing it reads acquires a name. **(a) Built by the caller, handed in as a `Source`** when it binds a resource the child's environment has to name before `execve`: the loopback forwarder, whose base URL must exist by the time `childSpec` is built. **(b) Built by the runtime from a factory the caller supplied** when its input is named only during the run: the tier-2 kernel recorder, whose ring buffer is a pin directory keyed by a build hash `Backend.Prepare` computes. **(c) Built by the runtime directly** when its package imports nothing that imports the runtime: `derive.Steps`, which depends only on `pkg/spec/record`. `Deps` carries the first two, as `Capture []Source` and `ObserveFactory func(bpfHash string) (Source, error)`. Whichever shape applies, a component that is absent or fails to build emits a `gap` event naming why, and never a silence.

Why: the two constraints are independent and neither shape alone satisfies both. `internal/runtime/capture` and `internal/runtime/observe` both import `internal/runtime` for the `Source`, `Sink` and `RunRef` contracts — deliberately, so those four shapes have one definition and a capture source can be handed to `Deps.Capture` at all — which means the arrow points one way and the runtime cannot call their constructors. That argues for building everything in the caller. But the recorder's ring buffer does not exist until the enforcement tier has attached, which happens inside `Run`, so the caller has nothing to name. A factory is the only shape that lets the composition root stay in `internal/cli` while the construction happens at the moment the name appears. Making it a `Handle` method instead of a type assertion was rejected for the same reason ADR 0011 keeps tiers behind a capability matrix: tier 1 has no ring buffer and should not be made to answer a question about one.

Consequence: `internal/cli` is the composition root for anything the runtime cannot import, and the optional interfaces it implies (`enforce.KernelRecorder`, `runtime.LoopbackSource`) are type assertions on a handle or a source rather than methods every tier must carry. The cost is one indirection per component and a factory signature that names its input. The benefit is the one this ADR was written after paying for: four components in this codebase — the capture selector, the ledger's garbage collector, the kernel recorder and the step deriver — were complete, tested, and had no caller, because each satisfied the interface its consumer took and satisfying an interface is not wiring. A component that is only reachable through `Deps` is reachable by inspection: the shapes are enumerable and `Deps` is one struct. A sweep for packages with no production importer is the check that catches the next one, and it belongs in review rather than in CI, because a package that is legitimately unreachable in this phase (`internal/runtime/ask`, the harness adapters) is a normal state that a gate would have to be taught to ignore.
