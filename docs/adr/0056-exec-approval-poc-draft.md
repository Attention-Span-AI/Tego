# ADR 0056: exec approval (the POC draft): superseded by ADR 0044

Status: superseded 2026-10-16 by [ADR 0044](0044-ask-before-a-command-runs.md), before it was accepted.

0056 was the number of an exec approval draft of 2026-10-06, superseded by ADR 0044. Its decided parts (the
trace-gate, the notification hold with the exec stop for a vfork child, ask entries admitted at the launch-time floor,
the ask that outlives its requester, the exact key with the whole environment minus volatile names) and its measured
evidence were merged with the 2026-10-05 draft of ADR 0044 into ADR 0044, which also decides the draft's provisional
and open items. Nothing under this number is a decision; the number is kept so that the draft's references resolve.
