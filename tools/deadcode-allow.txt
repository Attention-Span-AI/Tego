# ADR 0029 (4): every function deadcode finds unreachable from ./cmd/tego in any analyzed profile
# (linux amd64/arm64 x plain, integration, tegobpf, integration+tegobpf) is classified here by exact
# function, one per line: <import path>.<function>\t<class>\t<reason>. Classes (tools/deadcodereport):
#   public-api   exported from pkg/ for other consumers; the binary does not call it (pkg/ paths only)
#   placeholder  an ADR 0015 deferred surface
#   pending      built ahead of an accepted ADR's migration; the reason names the ADR and work package
#   tag-only     reached only under a build tag the binary is not built with (tegotesthooks), or an
#                integration-tag bridge for another package's integration tests
#   test-api     exported for another package's tests, which its own _test.go files cannot serve
#   tool-only    called by a repository tool (tools/...) sharing the package so both share one format
#   control-only called by cmd/tego-control from a package the two binaries share; the reason names the caller
#   reflection   reached through a call the analysis does not follow (encoding/json decoder methods)
# A function only its own package's tests call is not classified: it moves into those tests. A
# classification no profile finds is stale and fails the ratchet, so this list only shrinks with the code.
